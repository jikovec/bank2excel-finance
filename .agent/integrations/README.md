# Integration discovery

Only real integrations are documented. [GitHub](github.md) serves source and
work-management state. The workbook's optional Frankfurter FX network flow is
owned by [pipeline documentation](../../docs/architecture/pipeline.md),
[commands](../../docs/commands.md), and source; toolkit work does not invoke it.

For each added integration identify canonical configuration, external service,
read versus write effects, tools/environment, project/organization binding, and
credential source without values. Enabled configuration never proves current
authentication or action authority. Never commit secrets or tokens.

No external project registry, Mind-Seed/MemPalace backend, Jira, cloud hosting,
or MCP integration is configured by this repository. Connector availability
alone does not configure or enroll it. Do not create speculative service files.
