# Shared project workflows

[Private-safe validation](private-safe-validation.md) is the shared process for
build, fix, review, verify, and source delivery. Existing command and testing
docs remain canonical command references; this workflow selects the safe lane.

Use a workflow for durable shared mechanics and a skill for task-specific
judgment. Add a new document only when a real recurring process needs it.
No deployment, migration, or provider-parity implementation process is currently
configured. Git/PR mechanics live in [their contract](../contracts/git-github.md).
