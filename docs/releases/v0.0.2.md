# v0.0.2 Release Notes

Release date: 2026-08-03

## Summary

v0.0.2 turns the original local finance-workbook repository into a documented,
privacy-bounded, memory-first project without changing application behavior.
It consolidates the documentation reorganization, Codex operating memory,
Obsidian and future-agent navigation, and the tracked structure for a private
point-in-time finance snapshot.

## Included

### Documentation and navigation

- Reorganized setup, maintenance, and privacy guidance into topic folders.
- Added the root project-memory and human finance entry points.
- Added current-state, decisions, commands, testing, security, architecture,
  API/CLI, source, connection, report, release, and handoff documentation.
- Added human-readable and machine-readable future-agent indexes.
- Added local-first Obsidian graph guidance while keeping `.obsidian/` state
  ignored.

### Finance vault structure

- Added a tracked finance-vault guide and explanation of the evidence flow.
- Added a Markdown current-situation template, a null-valued JSON example, and
  a JSON Schema contract.
- Added a tracked safety guide for `finance/private/` while keeping actual
  current-situation JSON and Markdown files ignored.
- Preserved the rule that unknown values are `null` and real balances,
  accounts, transactions, and personal notes never enter tracked templates.

### Privacy and repository safety

- Extended `.gitignore` coverage for private finance snapshots and local
  Obsidian metadata.
- Documented the boundary between shareable source/docs and private inputs,
  config, outputs, caches, reports, and snapshots.
- Removed machine-specific absolute checkout paths from tracked documentation.
- Kept ignored root reports as local evidence; only scrubbed reports belong in
  `docs/reports/`.

### Source-backed operating documentation

- Documented the current CLI options, supported transaction and investment
  parsers, supported tabular file types, workbook sheets, FX provider and
  modes, validation output, and parser-extension points.
- Recorded the current dependency, test, CI, licensing, and full-build gaps
  instead of presenting them as completed work.

## Compatibility

This release contains no changes to:

- `build_finance_workbook.py` or `bank_parsers/`;
- PowerShell setup/build scripts;
- dependency declarations;
- CLI behavior or parser registration;
- generated workbook sheets or validation behavior; or
- private input, config, output, cache, report, or finance-snapshot contents.

Existing local workflows remain unchanged. The primary user-visible change is
the expanded, connected documentation and finance-vault structure.

## Private And Local Content Excluded

The release intentionally excludes `.env`, non-example config, `input/`,
`output/`, `cache/`, root `reports/`, actual files below `finance/private/`,
`.obsidian/`, generated workbooks, and other ignored artifacts. Their existence
or local state is not evidence that they were published.

## Known Limitations

- No dedicated automated test suite or GitHub Actions workflow is present.
- `build_finance_workbook.py` imports `matplotlib`, but `requirements.txt` does
  not declare it.
- No license file is present.
- Full workbook validation depends on private local inputs and was not run for
  this documentation-only release.
- The repository is a local CLI and has no hosted deployment surface.
