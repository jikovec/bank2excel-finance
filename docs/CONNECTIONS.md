# Connection Map

This map shows how repository artifacts should point to each other.

## Docs To Source

- [Pipeline architecture](architecture/pipeline.md) owns the high-level flow and
  should link to `build_finance_workbook.py` and `bank_parsers/` concepts.
- [API and CLI surface](api/README.md) owns the CLI option list and parser
  extension points.
- [Source map](SOURCE-MAP.md) owns the compact path-to-responsibility map.

## Source To Validation

- Parser changes under `bank_parsers/` should be checked with:

```bash
python -m py_compile build_finance_workbook.py bank_parsers/common.py bank_parsers/investments.py bank_parsers/revolut.py bank_parsers/slsp.py bank_parsers/tatrabanka.py
```

- CLI-surface changes should be checked with:

```bash
python build_finance_workbook.py --help
```

- Build validation should be run only when the task requires it because builds
  read private input and rewrite ignored output, cache, and report files.

## Reports To Changes

- Root `reports/` is for local generated evidence and can contain private data.
- `docs/reports/` is for scrubbed summaries and documentation-work reports.
- When a tracked report documents a docs-only change, link it from
  [reports index](reports/README.md) and [documentation index](README.md).

## Workbook To Finance Snapshot

- [Finance Home](../01_Finance_Home.md) is the human-facing vault entry point.
- The workbook and validation report provide evidence for the ignored private
  snapshot; the snapshot is not automatically generated by current source.
- [Current-situation JSON schema](../finance/current-situation.schema.json)
  owns the machine-readable fields, while
  [How it works](../finance/how-it-works.md) owns definitions and refresh rules.
- Real values stay in `finance/private/`; tracked examples must use `null` or
  clearly fake values.


## Handoffs To Remaining Work

- Use [handoff index](../handoffs/INDEX.md) when future agents need operational
  context after an incomplete or intentionally deferred task.
- Handoffs should link to relevant docs and source areas, but must not copy
  private report contents, account identifiers, or transaction examples.

## Decisions To Affected Areas

- Preserve [decisions](decisions.md) for CLI-only shape, privacy boundaries,
  private root reports, docs-safe validation, parser extension rules, and FX
  rate handling.
- Add new decisions only when backed by user instruction, current repo docs, or
  implemented source changes.

## Obsidian Graph Connections

- [Obsidian guide](OBSIDIAN.md) owns local graph conventions.
- [Future-agent index](AGENT-INDEX.md), [source map](SOURCE-MAP.md), and this
  file are the main graph hubs for future work. [Finance Home](../01_Finance_Home.md)
  is the corresponding hub for personal-finance review.
- Use normal Markdown links plus tags for graph navigation; keep GitHub
  compatibility as the baseline.
